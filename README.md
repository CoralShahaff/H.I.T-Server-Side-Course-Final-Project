# Cost Manager - RESTful API לניהול הוצאות🛠️

## 📌תיאור הפרויקט
Cost Manager הוא שירות RESTful לניהול הוצאות, המאפשר למשתמשים לנהל תקציב, לעקוב אחר הוצאות לפי קטגוריות, ולהפיק דוחות חודשיים. המערכת פותחה ב-Node.js עם Express.js ומשתמשת ב-MongoDB Atlas כבסיס נתונים.

## 💡טכנולוגיות עיקריות
- **Node.js** + **Express.js** - לפיתוח ה-API
- **MongoDB Atlas** - לאחסון הנתונים
- **Mongoose** - לניהול סכמות הנתונים
- **JSDoc** - לתיעוד הקוד
- **Postman** - לבדיקה וולידציה של ה-API

## 🚀יכולות המערכת
✅ ניהול משתמשים – רישום, התחברות ואימות זהות
✅ הוספה, עריכה ומחיקה של הוצאות
✅ חלוקת הוצאות לפי קטגוריות
✅ הפקת דוחות חודשיים
✅ אבטחת גישה מבוססת JWT

## ⚙️התקנה והרצה מקומית
1️⃣ שיבו את הפרויקט:
   ```sh
   git clone https://github.com/your-username/cost-manager.git
   cd cost-manager
   ```
2️⃣ התקנת התלויות:
   ```sh
   npm install
   ```
3️⃣ הגדרת משתני סביבה (`.env`):
   ```
   MONGO_URI=your_mongodb_connection_string
   PORT=3000
   JWT_SECRET=your_secret_key
   ```
4️⃣ הרצת השרת:
   ```sh
   npm start
   ```

## 🔎בדיקות API
- ניתן לבדוק את ה-API באמצעות **Postman**.
- קיימת תוכנית בדיקות ייעודית לבדיקת הפעולות השונות במערכת.
